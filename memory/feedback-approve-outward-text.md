Reading DMs, comments and insights is always fine. **Sending** anything (DM, comment reply, post,
story) needs Tal's explicit yes on the exact text (and exact image + caption for posts) in this
conversation. Draft it, show it, wait. A yes for one message doesn't cover the next.
When Tal does approve, sending is fine, including through the `instagram-expert` subagent: the
caller passes "Tal approved this exact text" plus the text, recipient and account, and the agent
sends it verbatim. (Tal, 2026-11-19: "what if i explicitly ask for it?")
DM contents and cosplayers' personal details never go into git or memory files.
